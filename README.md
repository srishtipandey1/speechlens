# SpeechLens
Contrastive, explainable speech evaluation with temporal flaw grounding.

## Setup

From PowerShell, create and activate a virtual environment, then install the project:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python run.py setup
```

Run the test suite with:

```powershell
python run.py test
```

The `dataset`, `eval`, `reproduce`, and `serve` tasks are placeholders until their implementations are added.
